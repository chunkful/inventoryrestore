# Vanish

A well-made inventory restoration plugin for modern Paper servers.

## Features
- Full support for online and offline players
- Advanced recording capabilities including inventory, ender chest
- Preview feature with Chest user interface
- Additional flags for advanced use cases
- Command-based user interface with click components
- Full MiniMessage support

## Documentation
View the [Wiki](https://github.com/chunkful/inventoryrestore/wiki) for user documentation.

## AI disclaimer
Some classes contain code that has been AI-generated:

- `NBTSnapshotRestorer`

and matching code style.
